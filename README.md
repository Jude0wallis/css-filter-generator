# CSS Filter Generator

A visual tool for generating CSS image filters.

## Features

- Brightness
- Contrast
- Saturation
- Blur

## How to Use

Select an image and adjust the filter controls.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Adjust brightness and verify the preview.
- [ ] Change contrast, saturation and blur settings.
- [ ] Copy the CSS filter and compare the selected values.
